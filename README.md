# E-Commerce Product & Customer Analytics

## Business Objective
Analyzed e-commerce transaction data to understand revenue performance,
customer purchasing behavior, product performance, and geographic contribution.

## Tools Used
- Power BI
- DAX
- Power Query
- Excel

## Key KPIs
- Total Revenue: 10.67M
- Total Orders: 20K
- Total Customers: 4K
- Average Order Value: 534.40
- Repeat Customer Rate: 65.6%

## Analysis Performed
- Monthly revenue trend analysis
- Customer repeat-purchase analysis
- Top 10 products by revenue
- Top 10 countries by revenue
- Interactive Country and InvoiceDate filters
- Data cleaning and transformation using Power Query
- KPI creation using DAX

## Dashboard
Interactive Power BI dashboard covering sales, customer,
product, and geographic performance.
